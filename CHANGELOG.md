# Changelog

## 2026-09-24 — Straight topology links and separate navigation

- Replaced orthogonal cable routing with a single straight segment between each pair of connected devices, in the style of Packet Tracer.
- Cable endpoints meet the visible device boxes. Geometry is recalculated on resize, and interface labels sit beside each cable. Indicators mark both link ends.
- Preserved the ISP-to-router uplink, router-to-access-switch link, and five individually assigned access ports.
- LinkedIn, GitHub, VLR, and the résumé PDF now open in a separate browser tab/window using `target="_blank"` and `rel="noopener noreferrer"`. The PDF viewer provides downloading; the portfolio stays open.
- Added an automated check for separate-tab targets and opener protection. Existing security and integrity checks remain in place.
